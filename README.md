# Sijjil Enterprise — Corporate Infrastructure & Contracting Portal

A modern, fast, fluid multi-page corporate website for **Sijjil Enterprise**, an enlisted Bangladeshi contracting firm executing government and public sector infrastructure projects across three main divisions:
1. **Electro-Mechanical Division (MEP)**: Electrical wiring, power substations, transformers, central air conditioning (HVAC), backup diesel generators, elevators, water supply pumps, and fire safety systems.
2. **Civil Construction Division**: Multi-story concrete buildings, paved asphalt roads and highways, concrete bridges, water culverts, stormwater drainage canals, and building renovations.
3. **Software & Web Development**: Custom web applications, e-governance portals, mobile apps (Android & iOS), digital payment gateway integrations, and cloud databases.

Built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS**, **React Router v6**, and **Framer Motion** for natural, fluid 60-120fps animations without scroll-jacking or lag.

---

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS (Navy `#0B2545`, Gold `#E0A526`, Light Grey `#F4F6F8`, Slate `#1F2937`)
- **Routing**: React Router DOM, dynamic code-split lazy loading
- **Animations**: **Framer Motion** (`whileInView`, `AnimatePresence`, `motion.div`, `whileHover`, `whileTap`) for natural, silky smooth scrolling
- **Forms**: React Hook Form with accessible validation
- **Icons**: Lucide React

---

## 💻 Software & Web Development Division

The Software Development division is focused strictly on software engineering, web platforms, and mobile apps:
- **Web Applications & E-Governance**: Next.js 14/15, React.js, TypeScript, Tailwind CSS, Node.js, and Laravel.
- **Mobile Apps**: Flutter & React Native for Android and iOS, offline form caching with SQLite, GPS camera tagging, and Figma UI/UX prototypes.
- **Online Payments**: Direct integrations with bKash, Nagad, Rocket, Upay, and credit/debit card gateways with automated digital receipts.
- **Cloud & Databases**: PostgreSQL, MySQL, MongoDB, Redis, Docker containers, Linux servers, and AWS deployment.
- **5-Stage Software Delivery Lifecycle**:
  1. *Understanding Requirements*
  2. *UI/UX Design & Prototype (Figma)*
  3. *Coding & Development (Sprint demos)*
  4. *Testing & Quality Check*
  5. *Launch, Staff Training & Ongoing Support*
